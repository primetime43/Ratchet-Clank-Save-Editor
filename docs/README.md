# Research documentation

Browse by **platform → game → region/title ID → executable version**.

- [PlayStation 3](PS3/README.md)

Game-level notes describe shared formats and identify the samples used. Address maps, asset definitions and executable-specific findings belong under their exact region and version. `unknown` means the executable version has not been established; it is not a compatibility claim.

Research tools and tests mirror this hierarchy under `Tools/` and `Tests/`. Generic utilities stay at those roots. Original game binaries, extracted assets, saves and generated analysis output remain untracked; this organization does not move them.
